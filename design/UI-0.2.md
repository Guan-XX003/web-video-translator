# 0.2 界面设计

用户选择：白底、石墨黑、少量荧光青；优先扩大文案阅读区域。

## 设计系统

- 背景 #FFFFFF，主字 #182020，辅助字 #7A8585，分割线 #EDF0EF。
- 荧光青 #56EBD5 仅用于品牌小圆点、选中下划线、当前口播左侧细线；播放句底色 #F0FCF9。
- 系统无衬线字体；标题 18px；阅读标题 21px；中文正文 15px / 1.85；原文 12px / 1.7；工具栏 11–12px；时间戳等宽 10px。
- 水平内边距 24px，320px 宽度下缩至 18px。卡片圆角 12px，按钮圆角 9px；轮廓图标保持统一细线。
- 顶部品牌与设置 → 当前视频 → 状态与语言 → 折叠说明 → 语言标签 → 历史选择 → 阅读区 → 定位当前句 → 固定底栏。
- 仅视频信息使用浅描边卡片；正文开放排版。页头与底栏固定，正文区域独立滚动；短窗口支持整段主区域滚动。

## 保留的交互

当前视频自动跟随、双语/中文/原文、点击时间跳转、当前句定位、历史选择、复制与 TXT/SRT/JSON 导出、重试提取、设置保存、本机服务连接检查、音频停止、历史清空。

## 有意适配

设计图里的示例文案仅用于排版；实际界面使用原始识别与自动翻译结果，不裁剪、不用人工整理稿替换译文。处理状态保留后台真实信息；语言显示根据元数据生成，未知时说明“语言自动识别”。
