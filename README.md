# 网页口播中文助手

Chrome / Edge（116+）浏览器插件：识别当前网页播放的视频 / 音频口播，翻译为简体中文。TikTok 优先读取原始字幕；其他 HTTP / HTTPS 网页在点击插件图标授权后，通过标签页音频与本机 Whisper 识别，不依赖特定网站的字幕接口。

## Windows 一键便携版（0.4.0）

另提供 `Web-Video-Translator-Windows-0.4.0-x64.zip`，已包含 Windows Python、CPU 推理依赖、Whisper base 多语言模型、C++ 运行库和 Google 官方 Chrome for Testing。完整解压后双击「一键启动.bat」，自动预加载模型、部署插件、生成本机配对码并打开专用浏览器。无需另装 Python、下载模型、手动加载插件或填写配对码。

适用 Windows 10/11 Intel / AMD 64 位；解压约 867 MiB，建议至少预留 2 GB。浏览器使用 `%LOCALAPPDATA%\TikTokTranscriptZh` 内独立配置；不修改日常 Chrome 的策略或配置。新版普通 Chrome 限制命令行加载本地插件，因此使用随包专用 Chrome。播放视频后，仍需点击插件图标或按 Alt+Shift+Y 授权标签页音频。识别完全在本机，翻译仍需联网。专用浏览器不会自动更新，需要通过新版包更新。

启动器与打包脚本见 `windows/`、`scripts/package_windows.py`。Windows 包在 macOS 上组装，已验证依赖完整性、x64 PE 架构、包内模型断网推理及浏览器真实 HTTP 自动配对；**尚未在 Windows 实机执行**。包内提供「运行诊断.bat」。

## 0.4.0 通用网页音视频

点击插件图标（或 Alt+Shift+Y）授权当前网页后，即可使用本机模型识别该标签页发出的声音。YouTube、B 站、课程页和素材库等可尝试使用此通用录音路线；这些站点未逐站验证，不承诺全部播放器可用。插件只临时访问用户点击授权的网页，没有加入全站常驻权限。页面刷新或完整跳转后需重新授权；同页切换视频会使用独立记录。

## 先安装插件

1. 在 Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目中的 **`extension` 文件夹**（里面有 `manifest.json`）。如果使用 ZIP，请先完整解压。
4. 在浏览器工具栏的拼图菜单里固定「网页口播中文助手」。安装后刷新已打开的视频网页。
5. 打开视频网页，点击插件图标打开侧边栏并授权当前标签页音频。TikTok 的已有字幕自动提取，无需本机服务；其他网页请启动本机识别服务。

## 开启无字幕视频的本机识别

### Mac

双击项目根目录下的 **`启动本机识别.command`**，保留终端窗口。脚本首次运行会安装依赖，并下载默认 `base` 多语言模型（约 145 MB）。需要 Python 3.10–3.13；建议 Python 3.12。

如果系统不允许双击，可在终端执行：

```sh
cd "/你的路径/tiktok-transcript-zh"
chmod +x 启动本机识别.command
./启动本机识别.command
```

本次开发已为当前 Mac 建好 `.venv`，并缓存了 `base` 模型。直接运行现有文件夹的启动脚本即可；ZIP 不包含虚拟环境与模型，其他电脑首次使用需要安装下载。

### Windows

安装 Python 3.10–3.13，双击 **`启动本机识别.bat`**。Windows 启动脚本尚未实机验证。

### 配对与识别

1. 复制启动窗口打印的「配对码」。
2. 打开插件侧边栏右上角设置，粘贴到「本机服务配对码」，点击保存，再点「检测连接」。
3. 切换到普通视频网页，**点击浏览器工具栏中的插件图标**，允许捕获该标签页音频。也可以使用 `Alt+Shift+Y`（Mac 为 `Option+Shift+Y`；如有冲突，可在扩展程序快捷键设置中调整）。这个操作必须由用户触发，插件不能绕过浏览器授权。
4. 播放视频并取消静音。约每 15 秒输出一次识别结果；暂停或视频结束也会提交剩余片段。同一页面内切换播放器或视频时自动分开文案。完整刷新、页面跳转或跨站后，请再次点击插件图标授权。
5. 音频识别从**当前播放位置**开始。需要完整口播时，授权后从头播放一次。已有字幕则可以直接读取整段，无需完整播放。
6. 点击侧边栏「停止音频」可释放音频捕获，关闭标签页、刷新或页面跳转也会停止。视频暂停不会停止标签页授权。

> 音频只进入 `127.0.0.1:8765` 的本机服务，识别时不上传到外部服务器。模型缓存好后可以离线识别；字幕下载和默认中文翻译需要联网。没有启用麦克风权限。

## 使用文案

- **双语 / 中文 / 原文**：切换显示与复制内容。
- **复制**：按当前语言视图复制文案；尚未翻译时可切到原文复制。
- **导出**：TXT、带时间轴的 SRT、含原文与中文的 JSON。
- **点击时间**：可访问的播放器能跳转到对应口播位置；跨域内嵌等无法读取播放器时，显示录音经过时间，禁用跳转；「定位当前播放句」将文案滚动到正在播放的位置。
- **重新提取**：重读字幕，或者重试已有本机识别文案的翻译。
- **自动跟随**：在设置里关闭后停止开始新的提取和识别，已有任务可能完成。
- 最近 20 条处理结果保存在浏览器本地存储；通过「最近文案」查看、复制、导出旧文案，选择「跟随当前视频」回到实时视频。设置中可清空记录。

## 翻译方式与准确性

默认使用 Google 的免 Key、**非官方**翻译接口（`translate.googleapis.com`），会把口播文字发送给 Google。这个接口没有可用性保证，可能因网络、地区、限流而失败；原文会保留，可稍后重新提取重试。设置中可以关闭在线翻译，仅提取原文。

这版未内置付费 API 或离线翻译模型，也不需要 OpenAI Key。插件先将连续字幕片段合并为较完整的语句再翻译，以减少断句误译；跨句语境、俚语、品牌名仍可能不准确。本机 `base` 模型速度优先，音乐、人声重叠、口音和 15 秒片段边界会影响识别，不保证逐字准确。

## 模型选项

默认 `base` 适合先试用。质量不足时可切换 `small`；较慢电脑可用 `tiny`。不同模型需分别下载，`small` 约 480 MB。启动示例：

```sh
./启动本机识别.command --model small
# 已缓存模型后，强制只使用本地文件：
./启动本机识别.command --offline
# 直接启动（无需外部 FFmpeg，浏览器发送标准 WAV）：
.venv/bin/python server/server.py --model base --warmup
```

## 已知边界

- 支持普通 HTTP / HTTPS 网页的标签页音频，包括视频、音频和内嵌播放器；不是所有网站逐一适配和实测。直播可按片段识别，但未专门验证长时间直播。图片本身没有可识别口播。
- 浏览器内部页、扩展页面和 file:// 本地文件不支持；DRM / 受保护播放器可能没有可捕获音频。不会绕过网站播放或访问限制。
- 每次只识别一个已授权标签页；该标签页内所有声音（含广告、多个播放器）都会进入识别。播放器应正常播放并取消静音。
- 顶层或开放 Shadow DOM 播放器尽量使用媒体时间轴；跨域 iframe、闭合 Shadow DOM 或 Web Audio 无法访问进度时使用录音经过时间，无法跳转到视频。
- 只能提取网页实际暴露的字幕，无法直接读取烧录在画面里的文字。字幕不存在、受限或网页改版时，转用音频识别。
- 页面通过可见播放器、视频链接及媒体地址关联视频；无法关联视频 ID 时使用播放器媒体地址分隔识别结果，避免串用其他视频的字幕。
- 音频路线只识别**实际播放且有声音**的部分，快进跳过的内容不会自动补齐。倍速较高、其他播放器同时发声也会影响结果。切换视频时尚未处理完的旧片段会被丢弃，防止旧结果进入新视频。
- 单机处理队列上限为 8 段；识别跟不上时会提示暂停等待。不会无限缓存整段视频。
- 浏览器扩展需手动加载；未发布 Chrome 商店，也未签名打包 CRX。不要将 ZIP 直接拖入扩展管理页面。
- 不绕过网站登录、验证码或地域访问限制。应使用浏览器能正常播放的视频。

## 开发与验证

无需 Node 构建，无前端第三方运行时，无远程执行脚本；`extension` 可直接加载。

```sh
npm test
npm run check
npm run package
```

已验证：字幕 VTT/SRT/JSON 解析、按视频隔离元数据、中文 SRT 导出、音频降采样/WAV 编码、本机认证与来源校验、真实 Whisper 离线识别、Chrome 扩展加载、侧边栏语言切换/复制/下载/设置保存、320 和 390 像素宽度。测试时还从真实 TikTok 页面读取了 12 条原始字幕并合并语句在线翻译。具体测试记录见 `VALIDATION.md`。
